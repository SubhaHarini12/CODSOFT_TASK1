# Task 1 - To-Do List Application

## Objective
To develop a command-line To-Do List application using Python that allows users to create, update and track their daily tasks efficiently.

## Description
This is a simple menu-driven Python application that helps users manage their tasks by adding, viewing and updating them through the command line.

## Features
- Add Tasks
- View Tasks
- Update Tasks
- Exit Application
- Menu-Driven Command Line Interface

## Technologies Used
- Python 3
- Visual Studio Code

## How to Run
Open the terminal and run:

```bash
python todo.py
```

## Outcome 
This project demonstrates the use of Python concepts such as lists, loops, functions and conditional statements to build a simple task management application.
